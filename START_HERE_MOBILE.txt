MOBILE DEPLOYMENT (RECOMMENDED):
1. Keep this whole project together; do not upload only index.html.
2. Create a new GitHub repository and upload ALL files/folders from this package.
3. On Render, create a new Web Service and connect that GitHub repository.
4. Build command: pip install -r requirements.txt
5. Start command: gunicorn app:app
6. Open the Render URL. That URL is the complete website and portal.

LOCAL TEST (PC):
pip install -r requirements.txt
python app.py
Then open http://127.0.0.1:5000/

NOTE ABOUT DATABASE:
SQLite is included and works immediately. For a large production school system, migrate to PostgreSQL later.
